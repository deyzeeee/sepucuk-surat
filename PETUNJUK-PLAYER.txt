SEP UCUK — PLAYER MUSIK MP3 (12 HALAMAN)
=======================================

Perubahan yang dibuat:
- Player Play/Pause, bar progres dan waktu pada kartu lagu.
- Piringan hitam berputar saat musik dimainkan dan berhenti saat pause/selesai.
- Tiap penerima memiliki lokasi file MP3 masing-masing.
- Tautan lagu eksternal lama tetap tersedia.
- Jika file audio belum diunggah, player disembunyikan dan muncul petunjuk.
- Animasi mengikuti preferensi reduced motion; musik tidak autoplay.

CARA PAKAI
1. Pastikan kamu mempunyai izin untuk mengunggah/memutar setiap rekaman.
2. Taruh MP3 berikut di folder website/audio/ menggunakan nama file tepat seperti di bawah.
3. Unggah ISI folder website/ (bukan folder luarnya) ke hosting static yang kamu pakai.
4. Akses halaman QR yang lama: semua path /r/<id>/ tetap sama.
5. Periksa tiap halaman, klik 'Putar lagu'.

Catatan:
- Paket ZIP ini tidak berisi rekaman berhak cipta. Siapkan file audio yang telah
  memperoleh izin penggunaan, atau gunakan tautan ke layanan resmi yang sudah ada.
- Jangan mengubah nama direktori r/<id>; QR lama mengarah ke folder ini.
- Beberapa browser tidak memutar file audio dari file://. Untuk tes lokal, jalankan:
    cd website
    python -m http.server 8000
  lalu buka http://localhost:8000/r/<id>/
- Jika mengganti judul/lagu penerima, ganti juga MP3 pada audioUrl di JSON
  id="note-data" dalam halaman penerima yang terkait.
- Mengunggah MP3 membuat file tersebut dapat diakses publik melalui URL website;
  jangan mengunggah rekaman yang tidak boleh dipublikasikan.
